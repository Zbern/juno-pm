## Goal

Triage reported incorrect pension payments 

**Primary actor:** Agent + Human-in-the-loop

## Trigger

New message in #escalations tagged new reported issue; Urgent alert in #escalations of percentage of reports exceeds >5% 

## Steps & tools

**Pattern:** ReAct (single-agent reason-act-observe loop)

| Step | Action | Tool / model | Guardrail |
|---|---|---|---|
| 1 | Submits an incorrect pension payment report for the user | slack.read_thread(id), read-only | Agent can READ Slack #escalations + Strategy KB + HR System. Agent can WRITE to #pm-daily and create Jira stubs. Agent CANNOT edit Salesforce records, edit Jira tickets after creation, or post outside #pm-daily. |
| 2 | RAG retrieval for additional user queries (if applicable) | HR_System.lookup_arr(user_id), read-only |  |

**Schemas**

- HR_System.lookup_arr → {arr_usd, contract_end, churn_risk}.
- jira.create_stub → {ticket_id, url, status}.

**Memory (in or out of scope)**

- **Episodic:** In-scope, tool results, retrieved chunks, percentage scores. Lifetime: end of run.
- **Semantic:** In-scope, pension corporation's strategic taxonomy + Juno system prompt + PM preferences. Lifetime: indefinite, refreshed weekly. Out of scope, do NOT persist customer-specific contracts or PII.
- **Working:** In-scope, current thread, customer ID, ARR, retrieved KB chunks, current percentage score. Held in working context only.
- **External:** Slack thread API (read), Pension Strategy KB (read), Salesforce ARR lookup (read), #pm-daily channel (write), Jira (write, stub creation only).

## Human-in-the-loop

PM reviews any P0 with confidence < 70% before posting. Daily 8:55am: PM has a 5-min review window before the agent auto-posts to #pm-daily.

## Success & failure

- **Done when:** - Success: percentage of issues reported to #pm-daily when threshold <5%
- Failure: > 2 tool errors in a run → log + report 
- Escalation: Daily percentage of issues reported > 5% of total pension payment views
- Timeout: 90s wall clock → rerun fresh \
- **Fails safe when:** Agent can READ Slack #escalations + Strategy KB + HR System. Agent can WRITE to #pm-daily and create Jira stubs. Agent CANNOT edit Salesforce records, edit Jira tickets after creation, or post outside #pm-daily.
